# 数据来源说明

本文档记录项目使用的全部数据来源、授权边界与缺失情况。任何无法核验的数据都不应被填充为看似精确的结果。

## 1. 行政区划与街道目录

- 来源：深圳市民政局《深圳市行政区划信息概况》
- URL：https://mzj.sz.gov.cn/szmz/pc/bmxx/cyfwzy/content/post_2949169.html
- 发布时间：2026-05-06
- 覆盖：9 个行政区、大鹏新区 1 个功能区、74 个街道办事处
- 使用方式：静态目录 `data/districts.ts`，单元测试核对数量与唯一性
- 限制：官方页面提供名称与数量，不提供社区列表、街道边界或坐标

## 2. 社区（居委会/村级）名录

- 来源：国家统计局《统计用区划代码和城乡划分代码》整理数据（modood/Administrative-divisions-of-China 仓库，数据本身来自官方公开区划资料）
- URL：https://github.com/modood/Administrative-divisions-of-China
- 统计口径：2023 年统计用区划代码
- 覆盖：深圳 783 个社区居委会，74/74 街道全覆盖；已过滤保税区、合作区、机场等 5 个非街道功能单元
- 使用方式：`scripts/extract-communities.mjs` 生成 `data/communities.ts`
- 限制：基层治理调整可能导致个别社区与现状不一致，界面标注统计年份；不包含社区边界与坐标，社区定位通过地图服务按名检索

## 3. 区级边界

- 来源：高德 JavaScript API 2.0 DistrictSearch
- 使用方式：浏览器在线查询，不把边界批量下载后作为自有数据再分发
- 覆盖：以高德实际返回为准；大鹏新区按名称尝试，未返回时明确缺失
- 坐标系：GCJ-02
- 限制：不等同于政府测绘成果；页面保留高德版权与法定地图信息

## 4. 街道与社区精确边界

- 当前状态：未接入批量可靠边界
- 已核实线索：深圳政府数据开放平台存在"宝安区-街道边界"等历史数据集，授权与坐标系待进一步核实
- 策略：只显示目录与检索到的真实定位点；禁止使用圆圈、矩形、Voronoi 或手绘线冒充官方边界

## 5. 地图底图、建筑楼块、卫星图与 POI

- 来源：高德 JavaScript API 2.0（https://lbs.amap.com/api/javascript-api-v2/guide/abc/load）
- 使用方式：官方在线脚本加载；安全密钥经构建注入（默认官方前端方式，可选 Worker 代理）
- POI 图层（商圈、商场、城中村线索、小区、地铁、铁路、派出所、政务、学校、医院、公园）：高德 PlaceSearch / searchNearBy 按需检索
- 限制：检索接口有分页与配额限制，结果不代表全市完整目录；字段缺失时如实显示，不按名称猜测
- 禁止事项：不违规批量抓取、不把一次检索结果当完整数据集、不再分发受限数据

## 6. 小区成交和村落房价参考

- [深圳中原地产西乡成交记录](https://sz.centanet.com/chengjiao/xixiang/)及相关公开筛选页提供单套成交日期、面积与总价。详情显示截至 2026-11-19 本项目核验并收录的最近公开一笔，按总价除以建筑面积折算。
- 小区按行政区与名称精确匹配；同名异区、不同期数不合并。未收录的小区显示缺失。
- 麻布新村、高树围新村的月度参考均价来自 58 同城爱房页面。原页面未交代成交口径，界面明确标注为平台参考。
- 区级与全市快照留存于历史数据文件，当前界面采用地点级房价。

## 7. 地铁线路与出入口

- 全市线网在线交由[高德地铁图 JS API](https://lbs.amap.com/api/subway-api/subway-summary/)渲染。1号线西段站名与[深圳地铁官方资料](https://www.szmc.net/map/)核对。
- 点站后以高德 POI 精确匹配该站的出入口；出入口查不到时尝试定位实际站点，详情显示解析到的名称。

## 8. 街景、图片和视频

- 当前状态：未接入。详情页显示精致空状态
- 策略：仅使用官方嵌入、可核验拍摄时间与明确授权的资料；禁止抓取重新托管、禁止旧照冒充现状

## 9. 用户探索与收藏

- 存储位置：当前浏览器 localStorage
- 限制：跨浏览器/设备不同步；清除浏览器数据会丢失；无登录系统

## 10. 地图合规

- 高德 JS API 仅允许在线加载，禁止本地存储、混编、绕过版权标识与配额
- 公开发布需符合中国地图展示相关规定，保留审图号等法定内容
- 不使用公司设备或账号资源执行未经授权的私人项目操作
