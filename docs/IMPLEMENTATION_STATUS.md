## 高德在线地图验收

- 本地浏览器已加载真实深圳 3D 底图，9 个行政区边界可绘制。大鹏新区保留目录，在线服务未返回可匹配的区界。

- 本地服务和 Pages Function 使用同源高德代理。安全密钥由服务端读取，Web Key 在浏览器端用于加载 JS API。
- Cloudflare Pages 通过 Git 连接 `main` 后自动部署。构建配置和密钥设置见 README。
