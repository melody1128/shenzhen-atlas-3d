# 2026-11-19 工作日志

## 深圳城市图鉴 3D（Shenzhen Atlas 3D）

项目位置：当前工作区根目录。已从零完成一个可运行的深圳 3D 城市探索静态站点。

### 架构决策
- Next.js 16 + React 19 + TypeScript 严格模式，**纯静态导出**（`output: "export"`）适配 Cloudflare Pages 0 元托管；用户后续要求从局域网交付改为公网部署。
- 地图引擎：高德 JS API 2.0（官方在线加载）。安全密钥经构建脚本 `scripts/prepare-static.mjs` 注入 `public/atlas-config.json`；支持 `AMAP_SERVICE_HOST`（Worker 代理）或官方前端明文方式。
- Next App Router 的 `_` 前缀路由目录会被忽略：地图代理曾放 `app/_AMapService/` 导致路由失效，已改为普通路由 + rewrites；后随静态化整体移除。

### 数据快照（全部经真实来源核实）
- 10 区/新区 + 74 街道：深圳市民政局 2026-05-06 目录。
- 783 社区：国家统计局统计用区划代码（modood 仓库提取，`scripts/extract-communities.mjs`），过滤了 5 个保税区/合作区功能单元。
- 房价（2026-11-18 一次性采集）：全市 2026-10 约 5.64 万/㎡（乐有家/贝壳，深圳政府在线转载）；区级+板块用普睿数智 2026-10 月报；两种口径分开标注，禁止混用。小区级明确显示"暂无可靠成交数据"。
